# Apto Atelier

Native CSS themes for Apto. Start with Midnight, Sakura or Glacier, edit their
`theme.css` in your code editor, and import or link it from **Edit → CSS**.
Linked files update the live preview on save. Apply keeps a local snapshot;
Cancel restores the previous appearance. The catalogue contains reviewed,
versioned themes only. These starter themes are free and original (CC0-1.0).

Download packages from [starter themes](https://github.com/fouxd/apto-atelier/releases/tag/starter-themes-v1).
See [the CSS guide](CSS-GUIDE.md) and [submission instructions](SUBMISSION.md).
Submit a new theme through Issues with its package, screenshots and asset licences.
Reviews cover validation, readability, performance and permission to distribute assets.
Approved versions are immutable; changes require a new version and review.

This repository distributes themes only. The Apto client and experimental Creator
build are distributed separately. Paid themes and an upload portal are future work.
