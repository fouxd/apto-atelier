# Submit a theme to Apto Atelier

Attach your `.apto-theme` package and screenshots of both supported layouts.
Provide name, stable ID, version, author, description, asset licences, supported
layouts and CSS API version 1. Explain any bundled images or fonts and confirm
you may distribute them. Run the package validator before submitting.

Maintainer review: validate package; verify licences and hash; inspect controls,
text, large GUI scale, resource reload, Apply/Cancel and frame timing. Publish the
exact approved package as an immutable versioned download, then add its hash and
metadata to catalogue.json. Changed packages require a new version and review.
